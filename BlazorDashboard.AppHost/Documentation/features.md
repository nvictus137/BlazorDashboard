# Features

| Page | What it shows |
| --- | --- |
| `/` | Overview with KPI cards, a seven-day revenue chart, fulfillment counts, and a recent-orders table that can be filtered by status. |
| `/counter` | An interactive Blazor Server counter. |
| `/weather` | Forecasts loaded from the Aspire-managed API, with a fallback message if the API is unavailable. |

The shared shell provides desktop navigation and a mobile drawer. The overview uses illustrative data bundled with the web project. The Aspire dashboard shows the web and API resource states.
