# Requirements

## Local development

- Install the .NET 10 SDK.
- Make the Aspire CLI available on `PATH`. AppHost uses the CLI bundle and references Aspire AppHost SDK `13.6.4`.
- Use a modern browser for the Blazor dashboard.

## Template scope

- Run the dashboard and Weather API through the Aspire AppHost.
- Provide a reusable dashboard shell with responsive navigation and KPI cards.
- Keep the example overview self-contained with sample data.
- Demonstrate interactivity and service discovery with the Counter and Weather pages.
